Italian Brainrot Daisensou is a swipe-controlled action game. No account or login is required.

Build 2 changes (response to Guideline 4.3 / 4.2.6): every character has a skill (Barrier, Magnet, Fever Boost, Lucky Drop or Mini Body); enemies now move in three ways (straight, wavy, chasing); the home screen is a 110-slot collection book with a coin bonus; background, gacha machine, items and HUD were redrawn.
How to see it quickly:
1. Home: the collection book (many "?" slots with rarity and skill icons) and the skill of the selected character (the starting character has Barrier).
2. Tap Start > Normal: the skill card is shown before the game begins. A blue bubble around the character absorbs one hit.
3. Wavy enemies (purple dashed ring) appear from 5 points; chasing enemies (red ring and "!") from 15 points.
4. Gacha (top right on Home): the starting 20 coins allow two spins; each result shows the skill. Hard mode unlocks after scoring 300 points in Normal mode.

How to play: swipe to move the character and dodge the enemies crossing the screen. Collect coins to open the gacha (coins only; there are no in-app purchases).

Version 1.0.1 changes: the app can be used by children, so all users are now treated as children. Ads (Google AdMob banner and rewarded) are requested with child-directed treatment (tagForChildDirectedTreatment = yes, tagForUnderAgeOfConsent = yes, max ad content rating G), non-personalized only, and there is no App Tracking Transparency prompt. The ranking display name is no longer typed by the user: it is generated from the install ID (e.g. "Player ab12"), so the app contains no user-generated content.

Ads: Google AdMob banner (bottom of game screens) and rewarded ads (to earn coins or revive).

Ranking: in Hard mode the app sends the score, the auto-generated name and a random per-install ID to Firebase Firestore. The name is shown to other players on the ranking screen. No other personal data is collected.

Characters are fan-made meme characters, declared as third-party content in App Store Connect. We will promptly remove any asset on request from the rights holder.
